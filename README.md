Multiplayer jet simulator made in Unity using Photon fusion 2 shared mode. You can create session or join a already created one and player with different people
in the same scene. Jet can lock to the enemy jets or dummy targets and release a missle that tracks them.
W S : used increase or deacrese thrust.
A D  :is for Yaw jet in left and right
Mouse X up and down : Pitch upword or downword
Mouse Y right and left : Roll Jet right or left
left click : Reasling the missle to the locked target
